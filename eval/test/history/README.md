# Historical audit evidence

These files preserve the earlier red-team and hardening runs. Old paths and
commands describe their original workspace; obsolete Python is retained as
`.py.txt` and old shell runners are archival evidence, not supported entrypoints.
Raw held-out predictions and answer-bearing artifacts belong exclusively here.
For the final runnable audit use `scripts/run_hardening.sh`; current results and
paired analysis are under `eval/test/final_results/`.
