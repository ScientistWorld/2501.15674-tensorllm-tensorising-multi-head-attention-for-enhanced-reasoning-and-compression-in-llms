Audit runners run inside the gym container on a compute node. Run `bash redteam/bundle.sh` to reproduce all checks. Every scenario has its own `run.sh`; each installs a default-path manifest, runs the visible evaluator, then invokes the unchanged hidden evaluator with **no arguments** as a separate process. No process or Python-environment tampering is used.

`harness.py` temporarily hides pre-existing score JSON files (future scientists receive only the four scoring documents), preserves their bytes and the default manifest, and restores them after each run. Method and shortcut inputs use the public dataset and predictions generated by our reference rerun. Hidden scores and the paper are used only by the audit analysis, never to construct shortcuts or select genuine improvements.

The scenario folders retain prediction artifacts, manifests, evaluator logs, exit codes and exact test scores. Large model inference artifacts are ignored; their compact prediction files are copied out. Reference code is snapshotted under state for audit reproducibility; improve-mode variants use the normal method module.
