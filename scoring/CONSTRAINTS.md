# Scientist Constraints

## Model

Use `roberta-base` as the base pretrained model for the `fever_roberta_binary` experiment. The benchmark is about post-training modification of a fixed model, so switching to a larger or instruction-tuned model would be resource scaling rather than methodological progress.

## Data

Use the deterministic FEVER subset generated by `data/prepare_fever.py` from `shared_task_dev.jsonl`. Do not add external labeled examples, use the held-out labels for tuning outside the scripted artifact format, or change the prompt template for reported scores.

## Evaluation

Report scores only through `scripts/evaluate.sh` from prediction artifacts. Do not edit `eval/` to special-case a proposed method, and do not include paper-reported numbers in `scoring/scores.json`.

## Compliance Checklist

- [ ] Base model is `roberta-base`
- [ ] Evaluation data is the provided FEVER binary subset
- [ ] Prediction artifacts include true labels, predictions, and NLL values
- [ ] `scripts/evaluate.sh` writes the reported `scoring/scores.json`
- [ ] Compression is measured for the modified MHA layer, not for unrelated parameters
